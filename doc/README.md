# Copy as Markdown - Design Documentation

## Overview
This directory contains design documentation for the Copy as Markdown browser extension.

## Documents

### [URL Copying Design](url-copying-design.md)
Comprehensive design document explaining how the extension copies URLs from browser address bars and pages into Markdown format. Covers:

- Architecture components and their responsibilities
- Data flow for URL copying operations
- Cross-browser considerations
- Testing strategies
- Security and performance considerations

## Purpose
These documents are intended for:
- Developers maintaining the extension
- Contributors understanding the codebase
- Technical writers documenting the architecture
